## Becoming a Maintainer

This is currently a single-maintainer project. As the contributor base
grows, maintainers may be added for specific services (particularly
`activity-service` and `gamification-service`, which have the most
independent domain logic). If you've made sustained, high-quality
contributions to a specific area and are interested in a maintainer role for
it, open an issue to discuss.

## Response Times

This is a side project maintained outside of full-time work, so please allow
for delays:

- **Issues / PRs**: best-effort, typically within a day.
- **Security concerns**: please flag these clearly in the issue title (e.g.
  `[SECURITY]`) so they can be prioritized.
